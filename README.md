# BOARD//BOX

**One app. Every game.** A mobile-first hub of quick board and arcade games. It's plain HTML, CSS and JavaScript, with no build step and no dependencies. You can install it on your phone as a PWA, and it works offline.

## Play

**Want it on your phone?** See **[docs/MAKING-IT-AN-APP.md](docs/MAKING-IT-AN-APP.md)**. It covers going live on GitHub Pages for free, installing to your home screen, and the Play Store and App Store routes.

To run it locally, serve the folder with any static server and open it on your phone or desktop:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

(Opening `index.html` directly also works, but offline/install support needs http(s).)

## What's in it

| Game | Modes |
|------|-------|
| ♟️ Chess | Bot (easy / medium / hard), 2 players. Play as White or Black. Full rules (castling, en passant, promotion picker, 50-move, repetition, insufficient material), move list, undo |
| 🟠 Checkers | Bot (easy / medium / hard), 2 players. American rules: forced captures, multi-jumps, kings |
| ⚫ Reversi | Bot (easy / medium / hard, solves the endgame), 2 players, legal-move hints |
| ❌ Tic-Tac-Toe | Bot (easy / unbeatable minimax), 2 players |
| 🔴 Connect 4 | Bot (easy / medium / hard alpha-beta search), 2 players |
| 🔢 2048 | Swipe or arrow keys, best score |
| 💣 Minesweeper | Easy / medium / hard, safe first tap, long-press or flag mode, chording, best times |
| 🐍 Snake | Swipe, arrows/WASD or on-screen pad, speeds up as you grow |

Hub features:

- **Daily Challenge**: three challenges a day that are the same for everyone, built from a date seed:
  - ♟️ **Chess Puzzle**: mate in 2 from a set of 120 generated puzzles.
  - 🔢 **Daily 2048**: today's board; reach the 512 tile.
  - 💣 **Daily Sweep**: today's medium board, with a safe starting patch already open.

  Completing any of them keeps your 🔥 streak going.
- **Achievements**: 25 trophies for beating the hard bots, high scores, roulette runs and streaks. A pop-up shows when you unlock one.
- **Profile**: win rate, streak, a 14-day daily history, every trophy and per-game bests.
- **Today's Pick**: the same featured game for everyone each day.
- **🎰 Play Something (Game Roulette)**: spins through the games and picks one at random. You get a 5-minute run.
- **Stats**: games played, wins and best scores are saved on the device in `localStorage`.
- Black/white UI with orange accents. It follows the system light or dark theme.

## Tests

```sh
npm test
```

- `tests/chess-perft.js` checks the chess engine against standard [perft](https://www.chessprogramming.org/Perft_Results) move counts, which cover castling, en passant, promotion and pins. It also checks mate, stalemate and draw detection, move notation, and that the bot finds a mate.
- `tests/logic.js` checks that daily seeds give the same board on every device, and that streak counting, best scores and achievement unlocks work. It also checks that **every puzzle is a genuine, unique mate in 2**.

The chess puzzles are generated by `npm run puzzles` (`tools/gen-puzzles.js`). It plays bot-vs-bot games on every CPU core and keeps positions where exactly one first move forces mate in 2, so every puzzle is correct by construction.

## Adding a game

Create `js/games/<name>.js`:

```js
BB.register({
  id: 'memory',
  name: 'Memory',
  icon: '🧠',
  tagline: 'Find the pairs.',
  mount(stage, api) {
    // render into `stage`, put controls in `api.toolbar`
    api.status('Your move');
    // when a game ends: api.record('win' | 'loss' | 'draw' | 'done', { score, level })
    // (achievements in js/achievements.js can then react to it)
    return () => { /* clear timers + global listeners */ };
  },
});
```

Then add a `<script>` tag in `index.html` and the path to `FILES` in `sw.js`. It shows up on the home screen and in the roulette automatically.
